# 🍊 Orange Task Farm (오렌지 할 일 측정소)

## Product Requirements Document

- Version: MVP v1.1
- Updated: 2026-09-08
- Status: 기획 확정, 구현 전

## 1. 제품 목표

Orange Task Farm은 완벽주의와 압도감 때문에 시작하지 못하는 사람이 큰 목표를 아주 작은 첫 행동으로 바꾸고 실제로 시작하도록 돕는 AI 웹서비스다. 최우선 가치는 생산성이나 연속 달성이 아니라 **시작(Start)** 이다. 사용자가 쉬거나 목표를 보관해도 실패, 손실, 죄책감을 느끼게 하지 않는다.

주요 사용자는 큰 목표 앞에서 시작을 미루거나 작은 성공 경험이 필요한 20~30대 대학생, 취업 준비생, 직장인이다.

## 2. 핵심 개념과 Core Loop

### 최종 목표와 첫 행동

- `finalGoal`: 사용자가 최종적으로 이루려는 유한한 목표
- `starterAction`: 최종 목표를 시작하기 위해 3분 안에 완료할 수 있는 첫 행동

둘은 별개이지만 연결되어 있다. 목표 줄이기 과정에서도 최종 목표는 보존하며, 연결된 첫 행동만 3분 이내 크기가 될 때까지 줄인다.

```text
책 한 권 읽기 (최종 목표)
→ 한 챕터 읽기
→ 한 페이지 읽기
→ 첫 문단 읽기 (3분 행동)
```

### Core Loop

```text
최종 목표와 맥락 입력
→ AI가 목표 크기(cm)와 이유 제시
→ 유한한 완료 기준과 진행 단위 확정
→ 연결된 3분 행동 찾기
→ 1분 안에 실제 시작
→ 시작 확인과 씨앗 생성
→ 최종 목표 진행률 입력
→ 성장
→ 100%에서 열매 준비
→ 사용자가 수확
→ 기록장과 도감 저장
```

## 3. AI 목표 분석

입력은 최종 목표와 선택적 맥락이다. AI는 다음을 구조화된 형식으로 반환한다.

- 정리된 최종 목표
- 고정 단계형 오렌지 cm와 판단 이유
- 유한한 목표인지 여부와 추천 완료 기준
- 추천 진행 단위와 이유
- 사전정보 없이 실행 가능한 3분 행동
- 3분 이내 완료 가능 여부

AI는 제공되지 않은 책 내용, 프로젝트 구조, 작성할 문장 등을 추측하지 않는다. 책 꺼내기, 다음 한 문장 읽기, 문서 열기, 독후감 한 문장 적기, 첫 세트 시작하기처럼 맥락 없이도 안전한 행동을 제안한다.

최초 씨앗 생성 전에는 사용자가 수정한 행동도 3분 기준으로 재검증한다. 씨앗 생성 후 추천 행동은 참고용이며 검증을 강제하지 않는다.

## 4. Orange cm

cm는 물리적 크기나 개인별 기분 점수가 아니다. 행동 범위, 완료 기준, 하위 단계 수, 준비 조건, 목표 유형의 일반적 부담을 고정 항목으로 평가한다.

허용 값:

```text
0.5 / 1 / 2 / 3 / 5 / 10 / 20 / 30 / 50 / 75 /
100 / 150 / 200 / 300 / 500 / 1,000 / ∞ cm
```

- 0.5cm: 준비 행동 — 책 꺼내기, 자리에 앉기
- 1cm: 최소 행동 — 한 문장 읽기
- 3cm: 3분 이내 완료 가능한 작은 행동 — 한 문단 읽기
- 10cm: 기본 작업 단위 — 한 페이지 읽기
- 30cm: 하위 묶음 — 한 챕터 읽기
- 100cm: 하나의 유한한 전체 목표 — 책 한 권 읽기
- 300cm 이상: 여러 단계가 연결된 복합 목표
- ∞cm: 완료 기준이 없거나 끝이 없는 목표

AI는 목록 외 값을 출력할 수 없다. 3분 가능 여부는 cm와 별도 필드로 판정하되, 통과 행동은 원칙적으로 3cm 이하다.

## 5. 유한 목표 규칙

`운동하기`, `취업 준비하기`, `영어 잘하기`처럼 끝이 없는 목표는 `∞cm`로 표시한다.

- AI가 유한한 완료 기준과 동일 단위 진행 방식을 추천한다.
- 유한한 기준이 확정되기 전에는 시작 확인 체크와 씨앗 생성을 차단한다.
- 씨앗 생성 후 최종 목표를 무한 목표로 수정하려 하면 경고와 함께 저장을 차단한다.
- 기존 씨앗과 진행 기록은 보존한다.

예: 운동하기 → 운동 10회 하기 → 0/10회. 기간은 선택적 범위 정보이며 실패나 압박 수단이 아니다.

## 6. 3분 행동과 씨앗

3분 행동은 구체적인 동사와 대상이 있고, 추가 계획 없이 바로 실행할 수 있으며, 필요한 도구를 즉시 또는 1분 안에 열 수 있고, 완료 여부가 명확하며, 일반적인 사용자 기준으로 3분 이내 완료 가능해야 한다. 자료 열기, 책 꺼내기, 자리에 앉기 같은 준비 행동도 유효하다.

```text
시작 버튼
→ 60초 카운트다운
→ 사용자가 `시작했어요`
→ 최종 목표에 연결된 씨앗 생성
```

- `마쳤어요`는 선택적인 축하 버튼이며 씨앗 생성이나 진행률의 조건이 아니다.
- `한 번 더 준비할래요`는 같은 행동과 타이머를 다시 시작한다.
- `다음에 시작할게요`는 목표와 행동을 저장한다. 실패 기록과 씨앗은 만들지 않는다.

## 7. 진행률과 성장

성장은 첫 행동이 아니라 최종 목표 전체 진행률만 사용한다. 시간 경과와 앱 사용 시간은 성장량에 영향을 주지 않는다.

AI가 진행 단위를 추천하고 이유를 보여주며, 사용자는 가중치 없이 진행 단위만 바꿀 수 있다. 지원 단위는 페이지, 항목/체크리스트, 강의/회차, 세트, 구역, 참여 일수, 사용자가 이름 붙인 동일 단위다. 모든 단위는 동일 비중이다.

100일 도전은 연속 일수가 아니라 실제 참여 일수를 누적한다. 쉬거나 놓친 날에는 감소, 초기화, 실패 표시가 없다.

수확 전에는 전체 범위와 진행률을 자유롭게 정정한다. 단계가 낮아져도 `진행 상태를 다시 맞췄어요`처럼 순화된 언어를 사용하며 불이익은 없다.

고정 성장 구간:

- 0%: 씨앗
- 1~25%: 새싹
- 26~60%: 나무
- 61~99%: 꽃
- 100%: 열매 준비

100%에서도 자동 수확하지 않는다. 사용자가 크고 귀여운 `수확하기` 버튼을 눌러야 품종 추첨, 기록 생성, 도감 등록이 일어난다.

## 8. 활성 목표와 동결창고

- 활성 목표는 최대 3개다.
- 네 번째 목표를 활성화하려면 기존 목표 하나를 동결창고로 옮긴다.
- 동결창고는 수량과 기간 제한이 없다.
- 씨앗, 성장 단계, 진행률을 보존한다.
- 성장 감소, 품종 확률 불이익, 실패 표시는 없다.
- 사용자가 원할 때 즉시 다시 활성화한다.

## 9. 재방문 경험

각 활성 목표 카드에는 추천 행동을 작은 말풍선으로 표시한다.

```text
💬 추천: 책을 펼쳐 다음 한 문장을 읽어봐요
                         [👆 이 행동으로 시작]

[ 내가 시작할 작은 행동을 입력해요                 ]
```

버튼을 누르면 추천 문장을 입력칸에 복사하고 사용자는 자유롭게 수정한다. 성장 중에는 타이머, 확인, 완료 체크, 3분 검증을 요구하지 않는다. 추천 행동은 저장하며 사용자가 요청할 때만 다시 생성한다. 말풍선은 접을 수 있고 동결창고에서는 표시하지 않는다.

## 10. 수집과 보상

- 수확한 오렌지와 기록은 영구 보관하고 소비하지 않는다.
- 기본 오렌지의 등장 확률이 가장 높다.
- 특별 품종은 조건을 만족한 경우에만 낮은 고정 확률로 추첨한다.
- 점진적 확률 보정, 결제·광고·재시도 확률 상승은 없다.
- 중복 품종도 누적 수확 수와 기록에 포함한다.
- 상점 항목은 누적 수확 조건으로 해금한다.
- v2 꾸미기는 외형만 바꾸며 기능이나 확률에 영향을 주지 않는다.

기록장에는 대표 품종, 목표 이름, 시작일, 수확일, 소요 기간, 획득 조건과 특징을 저장한다.

## 11. 게스트 우선 계정

- 로그인 없이 목표 분석부터 씨앗 생성과 MVP Core Loop 전체를 사용한다.
- 게스트 데이터는 현재 브라우저에 우선 저장한다.
- 첫 씨앗 생성 후 계정 연결을 선택적으로 안내한다.
- MVP 계정 연결은 Google OAuth 하나를 우선 제공한다.
- 이메일 로그인은 Google 로그인을 사용할 수 없는 사용자가 실제로 확인될 때만 추가한다.
- 계정 연결 시 목표, 동결창고, 기록장, 도감을 동기화한다.
- 브라우저 데이터를 지우면 복구할 수 없음을 명확하고 부드럽게 안내한다.

## 12. 출시 범위

### MVP-0 — 핵심 가설 검증

- 게스트 우선 진입과 로컬 저장
- 목표 입력, AI 분석, 단계형 cm
- 유한 목표와 진행 단위 확정
- 최종 목표를 보존한 3분 행동 찾기
- 1분 시작과 씨앗 생성
- 활성 목표 3개와 동결창고
- 진행률 입력과 재방문 복원

검증 지표는 분석 완료율, 3분 행동 확정률, 시작 확인률, 첫 진행률 기록률, 재방문율이다. 사용자를 평가하는 UI에는 노출하지 않는다.

### MVP-1 — 성장과 수집

- 고정 성장 단계
- 수확 버튼과 건너뛸 수 있는 짧은 애니메이션
- 기본 및 조건부 확률 품종
- 기록장과 최소 도감

### Version 2

- 매일 주제별 레이드 하나 제공
- 사용자는 해당 주제에서 자기 행동을 정해 하루 한 번 완료
- 개인 순위, 기여도, 목표 인원, 공동 성공·실패 없음
- 참여 인원은 `오늘 523명이 함께했어요`처럼 정보로만 표시
- 누적 수확 해금 상점
- 오렌지와 농장 외형 꾸미기

## 13. Non-goals

- 연속 출석 보상 또는 패널티
- 목표 미달, 휴식, 동결에 대한 실패 처리
- 진행률 가중치
- 앱 사용 시간에 따른 성장
- 경쟁 순위와 레이드 실패
- 소비형 오렌지 재화
- Core Loop를 잠그는 결제
- MVP의 복잡한 소셜 기능
