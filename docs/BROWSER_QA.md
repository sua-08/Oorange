# 브라우저 확인 목록

직접 화면을 확인할 때 사용한다. 기록은 현재 브라우저의 IndexedDB에만 저장된다. 기존 목표를 지우지 말고 새 테스트 목표를 사용한다.

## 시작과 측정

- 데스크톱과 좁은 모바일 화면에서 글자·입력칸·오렌지 그림·버튼이 겹치지 않는지 본다.
- 유한한 최종 목표와 현재 상황을 입력한다. 예: `강의 5개 듣기` / `첫날이고 시간이 10분 있어요`.
- 측정 결과에 원래 목표, cm, 이유, 첫 행동과 추천 행동이 표시되는지 본다.
- 3분 후보를 누르면 입력칸에 문장만 복사되는지, 다시 측정한 뒤에만 크기가 바뀌는지 본다.
- 행동을 여러 번 줄여도 원래 최종 목표가 그대로인지 확인한다.
- 끝이 없는 목표는 `∞cm`와 유한 목표 제안을 보여주고 시작 확인을 막는지 본다.

## 씨앗과 복원

- 씨앗 단계에서 1분 시작 후 `시작했어요!`를 눌러 씨앗을 얻는다.
- 씨앗이 첫 행동이 아닌 원래 목표를 대표하는지 본다.
- 타이머를 끝까지 기다린 뒤 다시 준비하거나 다음으로 미룰 수 있는지 본다.
- 새로고침 후 목표·첫 행동·씨앗이 복원되는지 본다.
- 목표 3개 이후 네 번째를 측정할 때 동결 안내가 나타나는지 본다.
- 동결창고에 보관하고 다시 활성화해도 기록이 유지되는지 본다.

## 성장·수확·도감

- 진행 단위와 전체량을 설정한다. 첫 행동만으로 진행률이 자동 증가하지 않는지 본다.
- 진행률을 올리고 정정한다. 100% 이전에는 수확 버튼이 없는지 본다.
- 100%에서 수확 버튼을 누른 뒤에만 기록장이 생기는지 본다.
- 같은 목표를 두 번 수확할 수 없는지 확인한다.
- `/encyclopedia`에서 품종 발견 여부와 누적 수확 수를 확인한다.
- 새로고침 후 기록장과 도감 수치가 유지되는지 본다.

## 화면과 오류

- 손그림 오렌지 이미지, 주황 버튼, 추천 말풍선, 수확 화면이 전달한 시안과 어울리는지 본다.
- 키가 없거나 분석 요청이 실패할 때 안내 문구가 나오고 기존 입력·결과가 사라지지 않는지 본다.
- Tab 키만으로 입력, 추천, 시작, 수확, 도감 링크를 이동할 수 있는지 본다.
